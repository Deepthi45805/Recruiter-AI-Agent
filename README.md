# Recruiter AI Agent

## Overview
AI-powered recruitment assistant built using Python, Streamlit, LangChain, Gemini, and SQLite.

## Features
- Resume Parsing
- Candidate Database
- Job Description Parsing
- Candidate Matching
- ATS Score Generation
- Interview Scheduling
- Analytics Dashboard

## Technologies Used
- Python
- Streamlit
- LangChain
- Google Gemini API
- SQLite
- Pandas

## Project Structure
- app.py
- resume_parser.py
- jd_parser.py
- candidate_matcher.py
- ats_score.py
- interview_scheduler.py
- analytics_dashboard.py

## How to Run

pip install -r requirements.txt

streamlit run app.py
